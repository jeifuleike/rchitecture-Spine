# 采样与稳定身份契约

## 允许的采样字段

| 字段 | 用途 | 持久化规则 |
| --- | --- | --- |
| `sampled_at_utc` | 确定采样时间与片段边界 | 可以 UTC 时间保存 |
| `display_name` | 向用户展示应用级摘要 | 可以保存 |
| `executable_name` | 无包标识时生成稳定身份 | 仅文件名；可以保存 |
| `package_identity` | 优先生成稳定身份 | 可以保存 |
| `idle_duration` | 供后续空闲判定使用 | 信号可携带；本故事不定义状态转换 |

## 禁止字段

- 窗口标题、网页标题、文档名、文件路径、URL、聊天对象和窗口内容。
- 键盘输入、鼠标轨迹、截图与任何屏幕像素数据。
- 进程 ID；它只能服务于一次前台查询，生成身份后必须丢弃。

## 稳定身份

1. 包标识存在时，身份键使用包标识。
2. 否则，显示名按 Unicode 规范化，和小写化的可执行文件名共同组成身份键。
3. 字段冲突时保留为不同身份，不猜测合并。
4. 完整路径与进程 ID 不得进入身份、日志或存储模型。

## 采样与短暂切换

- 前台窗口查询使用 `GetForegroundWindow`；采样默认间隔为 5 秒。
- 适配器只产生最小化信号，不写入片段。
- 协调器是唯一可根据连续信号创建、关闭、拆分或合并片段的组件。
- 当一个中间应用片段少于 15 秒，且其前后稳定应用身份相同，应合并回前后片段；其他切换保留为独立应用边界。
